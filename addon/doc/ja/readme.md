## アドオンのショートカット

- ファイルまたはフォルダーを MurCr に送信: NVDA+ALT+K  
- MurCr のプロジェクトディレクトリを開く: NVDA+ALT+K+K  

# MurCr とは？

MurCr は、音声/動画ファイルを処理して、さまざまな形式の出力を生成できる無料のアプリケーションです。  
このアプリケーションは、2014 年からトルコで活動している市民社会組織 Körüz.biz によって開発されました。

# MurCr でできること

このアプリケーションでは、次のタスクを実行できます。

- 音声/動画ファイルから 1 つ以上の時間範囲（セグメント）を抽出したり、選択した時間範囲を順番に結合して新しい動画を作成したりできます。
- メディアにトランジション効果やバックグラウンドオーディオを追加できます。
- 任意の画像を使って音声ファイルを動画に変換したり、既存の動画の映像出力または音声出力を無効にしたりできます。
- ディレクトリ内の音声/動画ファイルを 1 回の操作で結合し、異なる映像または音声のプロパティで出力できます。
- 音声/動画ファイルをさまざまな形式に変換し、出力品質を指定し、出力ファイルのサイズを MB 単位で制限できます。
- 音声/動画ファイルを、時間の長さまたはファイル数に基づいて均等に分割できます。
- MurText で作成した字幕ファイルを処理し、さまざまな外観や座標のオプションを使って動画に焼き込むことができます。

# 安全で管理しやすい

MurCr は、音声/動画の処理と作成の過程で、スマートなツールであなたをサポートします。

- **スマートカット:** スマートカットツールにより、MurCr は最速かつ最も正確なトリミングを目指します。管理しやすいコントロールツールを使って、最も安全な方法で操作を完了します。

- **スマートインターフェース:** お使いのデバイスと動画のサイズに基づいて、最適なインターフェースレイアウトを提供します。スマートなボタン管理により、インターフェースの好みを設定できます。

- **スクリーンリーダー対応:** NVDA および JAWS とのインタラクティブなインターフェースにより、快適なアクセシビリティを提供します。

- **保護メカニズム:** MurCr は常に、あなたが渡したファイルのコピーに対して作業します。ファイルがプロジェクトディレクトリにコピーされた後は、すべての操作がコピーされたファイルに対して行われます。

- **動画の解像度と FPS の競合検出:** MurCr は、作成または結合したいファイルを分析し、動画の解像度と FPS 値の違いを検出します。それに応じて出力ファイルで使用する値を決定します。最適な映像構成を準備するためのさまざまなオプションを提供します。

- **タイムラインの重複検出:** 分析により、同じソースに由来する重複した時間範囲を検出します。選択すれば、これらの時間範囲を自動的に結合できます。

- **正規化チェック:** MurCr は、動画の解像度や FPS 値などの違いによって生じるずれを最小限に抑えるため、ファイルを正規化します。0.2 秒を超えるずれが検出された場合、高速トリミングツールは使用されません。これにより、視覚的な認識に影響する可能性のある FPS の飛びやフレームのずれなどの問題を防ぎます。

- **ステレオ出力:** MurCr は、分割を除くすべてのタスクでステレオ出力を生成します。ステレオのソースファイルのチャンネルは保持されます。モノラルのソースでは、アクティブなチャンネルがもう一方のチャンネルに複製されます。また、低周波の音声を 48,000 Hz に引き上げ、ステレオの出力ファイルを得られるようにします。

- **レポート:** 統合されたレポートツールにより、作業中のファイルやプロジェクトディレクトリのサブフォルダー内の任意のファイルを、サイズ、動画の解像度、FPS、ステレオ/モノラルなどの基準で分析できます。HTML 形式に変換できるディレクトリレポートでは、スクリーンリーダーのショートカットを使ってすべてのファイルプロパティを簡単に確認できます。

# 柔軟な構造と高度なアクセシビリティ機能

MurCr は、柔軟なワークフローとアクセシビリティ機能により、満足のいくユーザー体験を提供します。

- **シンプルなワークフロー:** 1 つのキーを押すだけで、ファイル内のトリミングする範囲をマークできます。

- **選択はあなた次第:** 1 つのファイルでも、複数のファイルでも作業できます。

- **カスタマイズ可能なショートカット:** MurCr のインターフェース全体をキーボードショートカットで操作できます。ショートカットは好きなように変更でき、後でリセットすることもできます。

- **高度なアクセシビリティ:** MurCr は、専用に開発したショートカットおよびインターフェースエンジンによって、スクリーンリーダーのフォーカス管理機能を提供します。たとえば、「Alt+E」ショートカットが「タスクを完了」操作を実行する一方で、「Alt+K」を押してすぐに「Alt+E」を押すと、スクリーンリーダーのフォーカスが「タスクを完了」ボタンに移動します。有効なすべてのタスクのショートカットで使えるこの機能により、Tab キーを使わずに、アプリケーションのインターフェース内の目的の場所へ直接移動できます。

- **スマートウィンドウ管理:** ファイルの再生中にウィンドウが開いたことを MurCr が検出すると、スクリーンリーダーが読み上げるメッセージを落ち着いて聞き取れるように、再生を一時停止します。ウィンドウが閉じられると、再生は停止した位置から再開され、ウィンドウの切り替え後にスクリーンリーダーは静かになります。

- **オーディオとトランジションのアクセシビリティレポート:** メディアに適用したオーディオとトランジションの操作を .txt 形式で一覧にでき、スマートフレームキャプチャ機能でトランジションの瞬間を .png として保存できます。

- **高度な通知管理:** さまざまな目的で使われる通知や情報メッセージを、お好みに合わせて管理できます。

- **プロジェクトディレクトリ:** 作成したプロジェクトに名前を付けたり、別のディレクトリに移動したり、長い時間が経った後でも同じプロジェクトを再び開いて編集したりできます。タスクが完了したら、出力ファイルまたはプロジェクトディレクトリをクリップボードにコピーしたり、削除したり、新しいタスクに送ったりできます。

- **組み込みアドオン:** NVDA 向けに開発されたアドオンを設定セクションから有効にし、NVDA+ALT+K ショートカットでファイルを直接 MurCr に送信できます。

- **多言語対応:** MurCr のインターフェースは 11 の世界の言語で使用できます。
