# 什么是 MurCr？

MurCr 是一个免费的应用程序，可用于处理音频/视频文件并生成不同类型的结果。  
该应用程序由 Körüz.biz 开发，这是一个自 2014 年以来在 Turkiye 运作的公民社会组织。

# 使用 MurCr 可以做什么？

使用该应用程序，您可以执行以下任务：

- 从音频/视频文件中提取一个或多个时间段（片段），或将选定的时间段顺序合并以创建新的视频。
- 您可以为媒体添加转场效果和背景音频。
- 使用任意图像将音频文件转换为视频，或禁用现有视频的音频或视频输出。
- 将目录中的音频/视频文件一次性合并，并根据不同的音频或视频属性生成输出。
- 将音频/视频文件转换为不同格式，设置输出质量，并限制输出文件的大小（MB）。
- 根据时间长度或文件数量将音频/视频文件分割为相等的部分。
- 您可以处理使用 MurText 创建的字幕文件，并通过不同的外观和坐标选项将其烧录到视频上。

# 安全且可控

MurCr 在音频/视频处理和创建过程中为您提供智能工具支持。

- **智能剪辑：** 借助智能剪辑工具，MurCr 力求实现最快、最精确的剪辑。它通过可管理的控制工具，以最安全的方式完成您的操作。

- **智能界面：** 根据您的设备和视频的尺寸，提供最合适的界面布局。借助智能按钮管理，您可以设置自己的界面偏好。

- **屏幕阅读器兼容性：** 借助与 NVDA 和 JAWS 的交互式界面，提供舒适的无障碍体验。

- **保护机制：** MurCr 始终在您提供文件的副本上工作。文件复制到项目目录后，所有操作都在副本上执行。

- **视频分辨率和 FPS 冲突检测：** MurCr 会分析您要创建或合并的文件，检测视频分辨率和 FPS 值的差异，并据此确定输出文件使用的值。它提供多种选项，以准备最合适的视觉配置。

- **时间轴重叠检测：** 分析会检测来自同一来源的重叠时间段。如有需要，这些时间段可以自动合并。

- **规范化检查：** MurCr 会对文件进行规范化，以尽量减少由视频分辨率和 FPS 值等差异造成的偏差。如果检测到超过 0.2 秒的偏差，则不会使用快速裁剪工具。这有助于避免可能影响视觉感受的问题，例如 FPS 跳变或画面偏移。

- **立体声输出：** 除分割任务外，MurCr 在所有任务中都会生成立体声输出。它会保留立体声源文件的声道。对于单声道源文件，会将当前声道复制到另一声道。它还会将低频音频提升至 48,000 Hz，使您可以获得立体声输出文件。

- **报告：** 借助内置报告工具，您可以根据大小、视频分辨率、FPS 以及立体声/单声道等条件，分析当前正在处理的文件或项目目录子文件夹中的任意文件。目录报告可转换为 HTML 格式，让您使用屏幕阅读器快捷键轻松查看所有文件属性。

# 灵活结构和高级无障碍功能

MurCr 通过灵活的结构和无障碍功能提供良好的用户体验。

- **简单操作：** 只需按下一个键即可标记文件中需要剪切的区域。

- **由您决定：** 您可以处理单个文件或多个文件。

- **可自定义快捷键：** MurCr 的整个界面都可以通过键盘快捷键进行控制。您可以按自己的意愿更改快捷键，也可以稍后重置。

- **高级无障碍功能：** MurCr 通过专门开发的快捷键和界面引擎提供屏幕阅读器焦点管理功能。例如，“Alt+E”快捷键会触发“完成任务”操作，而先按“Alt+K”再立即按“Alt+E”，会使屏幕阅读器将焦点移到“完成任务”按钮上。借助这一适用于所有活动任务快捷键的功能，您无需使用 Tab 键即可直接跳转到应用程序界面中想要的位置。

- **智能窗口管理：** 如果 MurCr 在播放文件时检测到窗口弹出，会暂停播放，以便您能轻松听清屏幕阅读器朗读的消息。窗口关闭后，播放将从停止处继续，并且在窗口切换后屏幕阅读器会被静音。

- **音频和转场的无障碍报告：** 您可以将应用于媒体的音频和转场操作以 .txt 格式列出，并使用智能帧捕获功能将转场时刻保存为 .png。

- **高级通知管理：** 您可以按自己的意愿管理用于不同目的的通知和信息提示。

- **项目目录：** 您可以为所创建的项目命名，将项目移动到其他目录，并在很长时间之后重新打开同一项目进行编辑。任务完成后，您可以将输出文件或项目目录复制到剪贴板、删除，或发送到新任务。

- **内置插件：** 您可以在设置部分启用为 NVDA 开发的插件，并使用 NVDA+ALT+K 快捷键将文件直接发送到 MurCr。

- **多语言支持：** 您可以使用 11 种不同的世界语言来使用 MurCr 界面。
