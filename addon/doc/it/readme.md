# Che cos'è MurCr?

MurCr è un'applicazione gratuita che consente di elaborare file audio/video e ottenere diversi tipi di risultati.  
L'applicazione è stata sviluppata da Körüz.biz, un'organizzazione della società civile attiva in Turkiye dal 2014.

# Cosa puoi fare con MurCr?

Con l'applicazione puoi eseguire le seguenti operazioni:

- Puoi estrarre uno o più intervalli di tempo (segmenti) dai tuoi file audio/video oppure creare un nuovo video unendo sequenzialmente intervalli selezionati.
- Puoi aggiungere effetti di transizione e audio di sottofondo ai tuoi file.
- Puoi convertire file audio in video utilizzando qualsiasi immagine oppure disattivare l'uscita audio o video di un video esistente.
- Puoi unire file audio/video presenti in una cartella in un'unica operazione e ottenere un output con diverse proprietà audio o video.
- Puoi convertire i file audio/video in diversi formati, definire la qualità dell'output e limitare la dimensione del file di output in MB.
- Puoi dividere i file audio/video in parti uguali in base alla durata o al numero di file.
- Puoi elaborare i file di sottotitoli creati con MurText e incorporarli nel video con diverse opzioni di aspetto e coordinate.

# Sicuro e controllato

MurCr ti assiste con strumenti intelligenti durante il processo di elaborazione e creazione audio/video.

- **Taglio intelligente:** Grazie allo strumento di taglio intelligente, MurCr punta al taglio più rapido e preciso. Completa le tue operazioni nel modo più sicuro con strumenti di controllo gestibili.

- **Interfaccia intelligente:** Offre la disposizione dell'interfaccia più adatta in base alle dimensioni del dispositivo e del video. Grazie alla gestione intelligente dei pulsanti, ti consente di impostare le preferenze dell'interfaccia.

- **Compatibilità con i lettori di schermo:** Grazie alla sua interfaccia interattiva con NVDA e JAWS, offre un'accessibilità comoda.

- **Meccanismi di protezione:** MurCr lavora sempre su una copia del file fornito. Dopo che i file vengono copiati nella cartella del progetto, tutte le operazioni vengono eseguite sulle copie.

- **Rilevamento dei conflitti di risoluzione video e FPS:** MurCr analizza i file che vuoi creare o unire e rileva le differenze nella risoluzione video e nei valori FPS. In base a ciò determina i valori da usare nel file di output. Offre diverse opzioni per preparare la configurazione visiva più adatta.

- **Rilevamento delle sovrapposizioni nella timeline:** L'analisi rileva intervalli di tempo sovrapposti provenienti dalla stessa sorgente. Se lo desideri, questi intervalli possono essere uniti automaticamente.

- **Controlli di normalizzazione:** MurCr normalizza i tuoi file per ridurre al minimo le deviazioni causate da differenze come la risoluzione video e i valori FPS. Se viene rilevata una deviazione superiore a 0,2 secondi, gli strumenti di taglio rapido non vengono utilizzati. Questo aiuta a prevenire possibili problemi, come salti di FPS o spostamenti dei fotogrammi che possono influire sulla percezione visiva.

- **Output stereo:** MurCr genera output stereo per tutte le operazioni tranne la divisione. Conserva i canali dei file sorgente stereo. Per le sorgenti mono, il canale attivo viene duplicato sull'altro canale. Inoltre porta l'audio a bassa frequenza a 48.000 Hz, consentendoti di ottenere file di output stereo.

- **Report:** Grazie agli strumenti di report integrati, puoi analizzare il file su cui stai lavorando o qualsiasi file presente in una sottocartella della cartella di progetto in base a criteri come dimensione, risoluzione video, FPS e stereo/mono. Il report della cartella, convertibile in formato HTML, ti permette di esaminare facilmente tutte le proprietà dei file con le scorciatoie dello screen reader.

# Struttura flessibile e funzionalità di accessibilità avanzate

MurCr offre un'esperienza utente efficace grazie alla sua struttura flessibile e alle funzionalità di accessibilità.

- **Flusso di lavoro semplice:** Puoi contrassegnare le aree da tagliare nei file premendo un solo tasto.

- **La scelta è tua:** Puoi lavorare con un singolo file o con più file.

- **Scorciatoie personalizzabili:** L'intera interfaccia di MurCr può essere controllata tramite scorciatoie da tastiera. Puoi modificare le scorciatoie a piacere o ripristinarle in seguito.

- **Accessibilità avanzata:** MurCr offre la gestione del focus del lettore di schermo tramite il suo motore di scorciatoie e interfaccia sviluppato appositamente. Ad esempio, mentre la scorciatoia "Alt+E" attiva l'azione "Completa attività", premere "Alt+K" e subito dopo "Alt+E" fa spostare il focus del lettore di schermo sul pulsante "Completa attività". Grazie a questa funzione, valida per tutte le scorciatoie delle attività attive, puoi raggiungere direttamente il punto desiderato dell'interfaccia dell'applicazione senza usare il tasto Tab.

- **Gestione intelligente delle finestre:** Se MurCr rileva l'apertura di una finestra durante la riproduzione di un file, mette in pausa la riproduzione affinché il messaggio letto dal lettore di schermo possa essere compreso comodamente. Dopo la chiusura della finestra, la riproduzione riprende da dove si era interrotta e il lettore di schermo viene silenziato dopo il cambio di finestra.

- **Rapporto di accessibilità per audio e transizioni:** Puoi elencare in formato .txt le operazioni audio e di transizione applicate ai tuoi file e usare l'acquisizione intelligente dei fotogrammi per salvare i momenti di transizione come .png.

- **Gestione avanzata delle notifiche:** Puoi gestire a tuo piacimento le notifiche e i messaggi informativi usati per scopi diversi.

- **Cartella di progetto:** Puoi definire il nome del progetto che crei, spostarlo in un'altra cartella e riaprire lo stesso progetto per modificarlo anche dopo molto tempo. Al termine dell'attività puoi copiare il file di output o la cartella di progetto negli appunti, eliminarli oppure inviarli a una nuova attività.

- **Add-on integrato:** Puoi attivare dalle impostazioni l'add-on sviluppato per NVDA e inviare i tuoi file direttamente a MurCr con la scorciatoia NVDA+ALT+K.

- **Supporto multilingue:** Puoi usare l'interfaccia di MurCr in 11 diverse lingue del mondo.
