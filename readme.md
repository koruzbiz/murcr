# What is MurCr?

MurCr is a free application that allows you to process audio/video files and produce different types of output.  
The application has been developed by Körüz.biz, a civil society organization operating in Turkiye since 2014.

# What can you do with MurCr?

With the application, you can perform the following tasks:

- You can extract one or more time ranges (segments) from your audio/video files, or create a new video by merging selected time ranges sequentially.
- You can add transition effects and background audio to your media.
- You can convert audio files into videos using any image you choose, or disable the video or audio output of an existing video.
- You can merge audio/video files located in a directory in a single operation and produce output with different video or audio properties.
- You can convert your audio/video files into different formats, define the output quality, and limit the output file size in MB.
- You can split your audio/video files into equal parts based on time duration or file count.
- You can process subtitle files you created with MurText, and burn them onto your video using different appearance and coordinate options.

# Safe and controlled

MurCr assists you with smart tools during the audio/video processing and creation process.

- **Smart Cut:** Thanks to its Smart Cut tool, MurCr aims for the fastest and most precise trimming. It completes your operations in the safest way using manageable control tools.

- **Smart interface:** It offers the most suitable interface layout based on your device's and video's dimensions. Thanks to smart button management, it lets you set your interface preferences.

- **Screen reader compatibility:** Thanks to its interactive interface with NVDA and JAWS, it offers comfortable accessibility.

- **Protection mechanisms:** MurCr always works on a copy of the file you provide. After the files are copied into the project directory, all operations are performed on the copied files.

- **Video resolution and FPS conflict detection:** MurCr analyzes the files you want to create or merge and detects differences in video resolution and FPS values. It determines the values to be used in the output file accordingly. It offers different options to prepare the most suitable visual configuration.

- **Timeline overlap detection:** Analysis detects overlapping time ranges originating from the same source. If you choose, these time ranges can be merged automatically.

- **Normalization checks:** MurCr normalizes your files to minimize deviations caused by differences such as video resolution and FPS values. If a deviation greater than 0.2 seconds is detected, fast trimming tools are not used. This helps prevent possible issues such as FPS jumps or frame shifts that may affect visual perception.

- **Stereo output:** MurCr generates stereo output for all tasks except splitting. It preserves the channels of stereo source files. For mono sources, the active channel is duplicated onto the other channel. It also raises low-frequency audio to 48,000 Hz, allowing you to obtain stereo output files.

- **Reports:** Thanks to its integrated reporting tools, you can analyze the file you are working on or any file located in a subfolder of the project directory according to criteria such as size, video resolution, FPS, and stereo/mono. The directory report, which can be converted to HTML format, allows you to review all file properties easily using screen reader shortcuts.

# Flexible structure and advanced accessibility features

MurCr offers a satisfying user experience with its flexible workflow and accessibility features.

- **Simple workflow:** You can mark the areas to be trimmed in your files by pressing a single key.

- **Your choice:** You can work with a single file or with multiple files.

- **Customizable shortcuts:** The entire MurCr interface can be controlled using keyboard shortcuts. You can change the shortcuts as you wish or reset them later.

- **Advanced accessibility:** MurCr provides a screen reader focus management feature through its specially developed shortcut and interface engine. For example, while the "Alt+E" shortcut triggers the "Complete Task" action, pressing "Alt+K" and then immediately pressing "Alt+E" causes your screen reader to move focus to the "Complete Task" button. Thanks to this feature, which is valid across all active task shortcuts, you can move directly to the point you want in the application interface without using the Tab key.

- **Smart window management:** If MurCr detects a window opening while a file is being played, it pauses playback so that the message spoken by the screen reader can be understood comfortably. After the window is closed, playback resumes from where it stopped, and the screen reader is silenced after the window change.

- **Accessibility report for audio and transitions:** You can list the audio and transition operations applied to your media in .txt format, and use the smart frame capture feature to save transition moments as .png.

- **Advanced notification management:** You can manage notifications and information messages used for different purposes as you wish.

- **Project directory:** You can define the name of the project you create, move the project to a different directory, and reopen the same project for editing even after a long time has passed. When the task is completed, you can copy the output file or project directory to the clipboard, delete it, or send it to a new task.

- **Built-in add-on:** You can enable the add-on developed for NVDA from the settings section and send your files directly to MurCr using the NVDA+ALT+K shortcut.

- **Multi-language support:** You can use the MurCr interface in 11 different world languages.
